# Cellulose@GO 复合水凝胶 3D 模型

浏览器里可交互的纤维素 / 氧化石墨烯（GO）复合水凝胶示意模型，基于 three.js。

- `index.html`：复合水凝胶（纤维网络 + GO 片层与含氧官能团）
- `bighex.html`：大环示意，同一结构但六元环约放大 2.5 倍显示、片层更大（风格参照常见示意图）
- `graphene.html`：石墨烯单层
- `three-d-stage.js`：3D 查看与导出组件

所有文件放同一目录，用浏览器打开 `index.html` 即可（需联网加载 three.js）。拖动旋转、滚轮缩放，可调参数并导出 PNG / GLB / OBJ / SVG。

说明：这是示意性的结构可视化，不是分子动力学或实测结构。
